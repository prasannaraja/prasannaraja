A personal AI platform that combines my professional knowledge with a production-style **RAG architecture**.

**Highlights:**

- Multilingual knowledge base and semantic retrieval
- Grounded responses using source-bound career information
- React + TypeScript frontend
- Node.js + Express + Prisma + SQLite backend
- Gemini embeddings and vector retrieval
- FastAPI + Crawl4AI + Playwright crawling pipeline
- MCP stdio / JSON-RPC integration
- Prompt-injection and SSRF protection
- Telemetry and knowledge-gap analysis
- Docker, Nginx, Let's Encrypt and GitHub Actions
